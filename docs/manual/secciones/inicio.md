# Inicio

1. Después de conectarse, la app abre **Inicio** con el estado de la instancia, las sesiones y el último respaldo.
2. Revise **Uso de tablespaces**: el color avisa cuáles se están llenando.
3. Presione **Refrescar** para actualizar los datos.
