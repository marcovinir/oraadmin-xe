# Auditoría — aporte Persona 3

1. Abra **Auditoría → Políticas** para consultar las políticas existentes y su estado.
2. Seleccione **Crear política** y configure las acciones u objetos permitidos; revise el SQL antes de confirmar.
3. Utilice **Activar** o **Desactivar** solo cuando la aplicación habilite la acción para la política seleccionada.
4. Abra **Pista de auditoría**, filtre por fechas, usuario, acción o política; presione **Buscar** y seleccione un evento. Exporte CSV cuando lo necesite.
