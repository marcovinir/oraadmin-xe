# Respaldos

1. En **Nuevo respaldo**, elija **Por esquema**, **Por tabla** o **Full** y marque lo que quiere respaldar.
2. Revise el **Directorio** y el **Nombre del respaldo**; si lo desea, escriba una **Observación**.
3. Presione **Ejecutar respaldo**, revise el SQL y presione **Ejecutar**. Al terminar se abre el log.
4. En **Historial**, seleccione un respaldo y presione **Ver log**. En **Programados**, presione **Programar respaldo** para que se repita solo, aunque la app esté cerrada.
