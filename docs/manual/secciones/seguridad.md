# Seguridad: usuarios, roles y privilegios

1. En la pestaña **Usuarios**, presione **Crear usuario**, complete los datos y deje marcado **Otorgar CREATE SESSION** para que pueda conectarse.
2. Seleccione un usuario para cambiarle la **Contraseña…** o la **Cuota…**, **Bloquear**, **Desbloquear**, **Expirar clave** o **Eliminar**.
3. En **Roles y privilegios**, presione **Crear rol** y luego **Otorgar…** para dar roles o privilegios; use **Revocar** para quitarlos.
4. Revise el SQL en la confirmación antes de aceptar. Toda acción queda en la Bitácora.
