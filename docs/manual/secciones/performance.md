# Performance

1. En **Sesiones y bloqueos**, revise las sesiones; la lista se actualiza cada 5 s. Abajo, **Bloqueos activos entre sesiones** indica quién bloquea a quién.
2. Para liberar un bloqueo, seleccione la sesión bloqueadora, presione **Matar sesión…**, revise el SQL y presione **Ejecutar de todos modos**.
3. En **Métricas**, elija el **Muestreo** y presione **Iniciar monitoreo** para ver el gráfico en vivo; presione **Detener monitoreo** al terminar.
4. En **Esperas y memoria**, presione **Refrescar** y consulte **Eventos de espera**, **Top SQL**, **Memoria SGA / PGA** y **Operaciones largas**.
