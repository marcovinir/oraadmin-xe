# Perfiles

1. En **Seguridad**, abra **Perfiles**, presione **Crear perfil**, defina los límites y presione **Crear**.
2. Seleccione un perfil para ver sus límites y use **Editar límites…** o **Asignar a usuario…**. `DEFAULT` y los perfiles de Oracle son de solo lectura.
