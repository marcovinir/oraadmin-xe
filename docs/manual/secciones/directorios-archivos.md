# Directorios y archivos — aporte Persona 3

## Objetos DIRECTORY

1. Abra **Directorios y archivos → Objetos DIRECTORY** y consulte nombre, ruta, registro y estado.
2. Seleccione un directorio para ver sus privilegios **READ/WRITE** y los detalles del registro.
3. Para crear un directorio, presione **Crear DIRECTORY**, introduzca nombre y ruta válida y revise el SQL.
4. Utilice **Registrar existente**, **Otorgar READ/WRITE** o **Eliminar** únicamente cuando la aplicación habilite la operación; confirme las advertencias.

**Figura.** Objetos DIRECTORY registrados y verificación de la carpeta local.

## Archivos DMP y LOG

1. Abra la pestaña **Archivos**, seleccione un DIRECTORY activo y presione **Refrescar**.
2. Consulte la lista de DMP/LOG, sus tamaños, fechas y asociación con el catálogo de respaldos.
3. Seleccione un LOG para utilizar **Ver log**; los archivos LOG no se renombran ni eliminan desde esta pantalla.
4. Para un DMP autorizado, utilice **Renombrar DMP** o **Eliminar DMP**, revise el SQL y confirme únicamente si acepta las consecuencias. La eliminación conserva el historial como **ELIMINADO**.
