# Tablespaces — aporte Persona 3

1. Abra **Tablespaces** y consulte tamaño, estado, espacio libre y porcentaje utilizado.
2. Seleccione **Crear** para indicar nombre, ruta del datafile y tamaño inicial; configure **Autoextend**, **NEXT** y **MAXSIZE** si corresponde.
3. Seleccione un tablespace administrable para agregar o redimensionar datafiles y cambiar el estado, según los permisos disponibles.
4. Revise el SQL y las advertencias antes de confirmar; presione **Refrescar** para verificar el resultado.
