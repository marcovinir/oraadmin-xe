# Bitácora

1. Elija **Desde**, **Hasta**, **Módulo** y **Resultado**; si lo desea, escriba parte del nombre en **Acción contiene**.
2. Presione **Buscar**. Las acciones con error aparecen en rojo.
3. Seleccione una fila para ver su SQL y presione **Copiar SQL** si lo necesita.
4. Presione **Exportar CSV** para guardar la lista en un archivo.
